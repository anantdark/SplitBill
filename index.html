SplitBill

Log the meter.
Split the bill.

Android app for shared prepaid electricity meters — log readings and recharges, auto-split costs by usage, and see who should top up next. Sync a room across phones with a Room ID. Your data stays on your devices.

Get the app Beginner guide

One room. Fair splits.

Record → review balances → top up when it’s your turn. No spreadsheet required.

Built for shared meters.

Flatmates, family homes, small offices — one prepaid meter, many people.

  • Room setup

    Name your room, add members, pick yourself. Share the Room ID so everyone joins the same meter room.

  • Fair splitting

    Usage-based cost split from meter deltas. The member with the lowest balance is flagged to recharge next.

  • Log recharges

    Record meter reading plus recharge amount after every top-up. Edit mistakes from history anytime.

  • Cloud sync

    Optional pull-and-push sync across devices. Notifications when new logs arrive from the room.

  • Backups

    Export a local JSON backup anytime. Optional password encryption for file exports. Cloud payload is gzip-compressed.

  • Home widget

    Glance widget shows member balances on your home screen — no need to open the app for a quick check.

Three steps.

  1. 01

    Install

    F-Droid or the GitHub APK. Android 10+.

  2. 02

    Create or join a room

    Set up members on one phone, or paste a Room ID to join an existing meter room.

  3. 03

    Log every top-up

    After recharging the meter, log the reading and amount. Balances update for everyone.
