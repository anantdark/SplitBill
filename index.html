One prepaid meter.
Everyone knows who tops up next.

SplitBill is for flats that share a single prepaid electricity meter. Log each recharge, split cost by actual usage, and keep balances straight across roommates — without a spreadsheet or a group chat argument.

Download APK Setup guide
  • No account — data stays on your phone
  • Optional Room ID sync for multiple devices
  • Works fully offline after setup

What you actually do

Three screens, repeated after every meter top-up.

Check balances

See prepaid balances and who should recharge next.

Log a top-up

Record meter readings and the amount paid after each recharge.

Review history

Track monthly usage and fix a bad entry if someone mistyped.

Built for the meter room, not the app store

Practical features for shared prepaid setups.

Room + members

Name the flat, add everyone on the meter, pick yourself on each phone.

Usage-based split

Cost follows meter deltas — not an even split every time.

Room ID sync

Share one ID so every phone sees the same logs. Cloud sync is optional.

Local backups

Export JSON anytime. Add a password if you want the file encrypted.

Home widget

Glance at balances from your launcher without opening the app.

Open source

Read the code, build it yourself, no vendor lock-in. GitHub.
